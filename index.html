How Language Learning Games Work Under the Hood

Modern language games combine computational memory scheduling with Self-Determination Theory (SDT) and the MDA (Mechanics–Dynamics–Aesthetics) gamification framework. Below is the interactive breakdown of the cognitive loop and empirical effect sizes from peer-reviewed meta-analyses.

1. Spaced Repetition (HLR & SM-2)
-45% Prediction Error

Duolingo's Half-Life Regression (Settles & Meeder, ACL 2016) trained on 12.9M student-word records predicts when a word is about to be forgotten (p ≈ 0.5), cutting error by 45%+ and boosting daily retention by 12%.

2. DGBLL Vocabulary Gains
g = 0.962 (Large Effect)

Meta-analyses of Digital Game-Based Language Learning (DGBLL) demonstrate a large positive effect size (Hedges' g = 0.962) on L2 vocabulary acquisition compared to traditional non-gamified instruction.

3. Educational Gamification
g = 0.822 (5,071 Learners)

Li, Ma, & Shi (2023, Frontiers in Psychology) analyzed 41 studies (49 samples, N=5,071) and found a large overall effect (g = 0.822) when combining Mechanics, Dynamics, and Aesthetics (MDA).

4. University Equivalence
4–5 Semesters Parity

Jiang et al. (2021, Foreign Language Annals) showed learners finishing A2/half-B1 content achieved reading and listening proficiency comparable to 4–5 university semesters in half the time.

// Standalone Spaced Repetition (Half-Life Regression + SM-2) Engine
export class PolyglotSRS {
  constructor() {
    this.items = new Map();
  }

  // Register a vocabulary item with initial half-life h = 1.0 day and SM-2 EF = 2.5
  registerItem(id, data) {
    this.items.set(id, {
      id,
      ...data,
      halfLifeHours: 24.0,
      easiness: 2.5,
      elapsedHours: 6.0,
      streak: 0,
      reviews: 0
    });
  }

  // Recall probability p = 2^(-elapsed / halfLife) (Settles & Meeder, ACL 2016)
  getRecallProbability(item) {
    return Math.pow(2, -item.elapsedHours / Math.max(1, item.halfLifeHours));
  }

  // Record a player's response (isCorrect: boolean, reactionMs: number)
  recordReview(id, isCorrect, reactionMs = 2500) {
    const item = this.items.get(id);
    if (!item) return null;
    item.reviews += 1;
    // Grade quality 0..5 based on accuracy & response speed
    const quality = isCorrect ? (reactionMs < 2200 ? 5 : 4) : 1;
    // Update SM-2 Easiness Factor
    item.easiness = Math.max(1.3, item.easiness + (0.1 - (5 - quality) * (0.08 + (5 - quality) * 0.02)));

    if (isCorrect) {
      item.streak += 1;
      // Exponentially grow memory half-life
      item.halfLifeHours = Math.min(720, item.halfLifeHours * (1.6 + 0.15 * item.easiness));
      item.elapsedHours = 1.0;
    } else {
      item.streak = 0;
      item.halfLifeHours = Math.max(4.0, item.halfLifeHours * 0.45);
      item.elapsedHours = 3.0;
    }
    return { ...item, recallProb: this.getRecallProbability(item) };
  }

  // Return items sorted by lowest recall probability (most urgent to review first)
  getNextDueItems(limit = 5) {
    return Array.from(this.items.values())
      .map(it => ({ ...it, recallProb: this.getRecallProbability(it) }))
      .sort((a, b) => a.recallProb - b.recallProb)
      .slice(0, limit);
  }
}
